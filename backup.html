আস্থা সমিতি — নিরাপদ ক্লাউড ব্যাকআপ

প্রতিটি Gmail-এর হিসাব আলাদা। Restore করার আগে বর্তমান ক্লাউড কপির স্বয়ংক্রিয় নিরাপদ Backup নেওয়া হবে।

Google অ্যাকাউন্ট যাচাই হচ্ছে…
Firebase প্রস্তুত হচ্ছে…

ব্যাকআপ ডাউনলোড

বর্তমান Gmail-এর ক্লাউড হিসাব JSON ফাইল হিসেবে ডাউনলোড করুন। চুক্তিপত্রের ফাইলগুলো Firebase Storage-এ থাকে; JSON-এ সেগুলোর নিরাপদ Storage Path থাকবে।

ব্যাকআপ ফিরিয়ে আনুন

এই Gmail-এর বর্তমান ক্লাউড হিসাব ব্যাকআপের তথ্য দিয়ে প্রতিস্থাপিত হবে। আগে বর্তমান ক্লাউড কপির একটি আলাদা Storage Backup তৈরি হবে।

ভিন্ন Gmail থেকে আসা ব্যাকআপ Restore করলে সেটির চুক্তিপত্রের Storage Path স্বয়ংক্রিয়ভাবে নতুন Gmail-এ স্থানান্তর হয় না। একই Gmail-এর Backup ব্যবহার করুন।
