আস্থা সমিতি — ক্লাউড ব্যাকআপ

আপনার Google অ্যাকাউন্টের Firebase ক্লাউড ডেটা JSON ফাইলে নামাতে বা আগে নেওয়া JSON ফাইল থেকে ফিরিয়ে আনতে ব্যবহার করুন।

সতর্কতা: ফিরিয়ে আনার সময় ক্লাউডের বর্তমান ডেটা নির্বাচিত JSON ফাইলের ডেটা দিয়ে প্রতিস্থাপিত হবে। আগে নিশ্চিত হয়ে নিন যে ফাইলটি সঠিক।

প্রথমে Google দিয়ে লগইন করুন।
