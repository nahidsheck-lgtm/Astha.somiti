# আস্থা সমিতি — GitHub Pages

এটি একটি static HTML/PWA অ্যাপ। আলাদা সার্ভার ডাটাবেজ ছাড়াই GitHub Pages-এ চালানো যাবে।

## GitHub Pages-এ প্রকাশ
1. GitHub-এ একটি নতুন repository তৈরি করুন।
2. এই ZIP-এর ভেতরের `index.html`, `manifest.webmanifest`, `sw.js`, `README.md` এবং `assets` ফোল্ডারসহ সবকিছু repository-র root-এ আপলোড করুন।
3. Repository → Settings → Pages → Deploy from a branch নির্বাচন করুন।
4. Branch হিসেবে `main` এবং folder হিসেবে `/ (root)` নির্বাচন করে Save করুন।
5. তৈরি হওয়া HTTPS Pages লিংক মোবাইল Chrome-এ খুলুন; চাইলে Install app / Add to Home Screen দিন।

## তথ্য সংরক্ষণ
গ্রাহক ও লেনদেনের তথ্য যে ব্রাউজারে অ্যাপ চালাবেন, সেই ব্রাউজারের Local Storage-এ থাকবে। অন্য ডিভাইসে স্বয়ংক্রিয়ভাবে সিঙ্ক হবে না। নিয়মিত অ্যাপের JSON backup ডাউনলোড করে নিরাপদে রাখুন। একাধিক ডিভাইসে একই ডেটা দরকার হলে পরবর্তীতে Firebase/Supabase-এর মতো সার্ভার ডাটাবেজ যুক্ত করতে হবে।

## গুরুত্বপূর্ণ
`file://` বা `content://` থেকে PWA ইনস্টল/অফলাইন ক্যাশ পুরোপুরি কাজ করে না। GitHub Pages-এর HTTPS লিংক ব্যবহার করুন।


## ডেটা ও নিরাপত্তা সতর্কতা
এই সংস্করণে তথ্য একই ব্রাউজারের Local Storage-এ থাকে; GitHub-এ বা অন্য ফোনে স্বয়ংক্রিয়ভাবে সিঙ্ক হয় না। এটি কোনো সার্ভার-সুরক্ষিত মাল্টি-ইউজার ডেটাবেজ নয়। বাস্তব সদস্য/আর্থিক তথ্য ব্যবহারের আগে নিরাপদ লগইন, সার্ভার ডাটাবেজ, ব্যাকআপ ও অ্যাক্সেস নিয়ন্ত্রণ যুক্ত করুন। পাবলিক GitHub repository-তে কখনো সদস্যদের ব্যক্তিগত তথ্য, পাসওয়ার্ড বা ব্যাকআপ ফাইল আপলোড করবেন না।
