==========================================

ভিত্তি: ব্যবহারকারীর দেওয়া Astha-Somiti-Final-Repaired.zip
সংশোধিত মূল ফাইল: index.html

সম্পন্ন পরিবর্তন
----------------
1. ড্যাশবোর্ডের চারটি হিসাবের বক্স মোবাইলেও এক সারিতে রাখার CSS override যোগ।
2. দৃশ্যমান গ্রাহক ID লেবেলগুলো ইংরেজি "ID:" করা হয়েছে; সংরক্ষিত ID মান পরিবর্তন করা হয়নি।
3. গ্রাহক তালিকায় নামের পরে মোবাইল নম্বর, তারপর আইকনসহ "লোনের পরিমাণ"; সপ্তাহ ও জমার তথ্যও রাখা হয়েছে।
4. টাকার বান্ডিল SVG আইকনের আকার বাড়ানো হয়েছে।
5. জমার স্লিপে গ্রাহকের নামের নিচে স্লিপের শিরোনাম, প্রশস্ত লেআউট, সম্পূর্ণ তারিখ ও স্পষ্ট জমার পরিমাণ; মোবাইলের জন্য responsive CSS।
6. পুরোনো backup-before-final.html এবং Firebase/PWA/অন্যান্য ফিচার ফাইল অক্ষত রাখা হয়েছে।

স্ট্যাটিক পরীক্ষা
----------------
- মূল HTML: head/body/title উপস্থিত; duplicate HTML id পাওয়া যায়নি।
- Inline JavaScript: ১০টি ব্লকের সবগুলো Node.js syntax check পাস।
- firebase-app.js এবং firebase-config.js: ES module syntax check পাস।
- CSS: ১৩টি style block parse করা হয়েছে; parse error পাওয়া যায়নি।
- ZIP: সব সদস্য ফাইলের CRC integrity পরীক্ষা করা হয়েছে।
- বিদ্যমান রিকভারি, restore/permanent-delete, ছবি, thumb image, NID/OCR,
  backup/import, reports/settings, Google login button এবং Firebase sync
  bridge-এর মূল কোড/চিহ্ন অক্ষত আছে।

গুরুত্বপূর্ণ
-----------
Firebase চালাতে ZIP extract করে index.html-এর সঙ্গে firebase-app.js,
firebase-config.js এবং বাকি সহায়ক ফাইল একই ফোল্ডারে রাখুন। HTTPS hosting
ব্যবহার করুন। Firebase-এর live setup না যাচাই করে সেটি সফল বলে দাবি করা হচ্ছে না।


পরবর্তী স্ক্রিনশট-ভিত্তিক সংশোধন:
- #app > nav.no-print-এ চার কলামের নির্দিষ্ট grid layout প্রয়োগ করা হয়েছে।
- বাটনগুলোর min-width/flex wrapping বন্ধ করে লেখা এক লাইনে রাখার নিয়ম যোগ করা হয়েছে।
- বিদ্যমান রং, ব্যাকগ্রাউন্ড, বর্ডার, আইকন ও বাটনের উচ্চতা/ভিজ্যুয়াল স্টাইল অপরিবর্তিত রাখার জন্য কেবল বিন্যাস-সংক্রান্ত CSS override করা হয়েছে।
- HTML-এ ৪টি ন্যাভিগেশন বাটন পাওয়া গেছে; inline JavaScript-এর ১০টি ব্লক Node syntax check-এ উত্তীর্ণ; duplicate ID পাওয়া যায়নি।
- বাস্তব Android/desktop browser screenshot পরীক্ষা এখনও করা যায়নি।


শেষ নির্দেশ অনুযায়ী রিকভারি ট্যাবের দৃশ্যমান নাম সরিয়ে শুধু গতিশীল সংখ্যা রাখা হয়েছে। অন্যান্য মেনু/নেভিগেশন CSS অপরিবর্তিত।

শেষ সপ্তাহের তারিখ:
- গ্রাহকের তথ্যের একদম শেষে আলাদা টেক্সট লাইনে "শেষ সপ্তাহের তারিখ" দেখানো হয়।
- হিসাব: c.startDate (লোন শুরুর তারিখ) + c.weeks × 7 দিন।
- উদাহরণ: ১৫ নভেম্বর ২০২৬ + ১২ সপ্তাহ = ৭ ফেব্রুয়ারি ২০২৭।
- তারিখ বাংলা locale-এ ফরম্যাট করা হয়; কোনো আলাদা ইনপুট ঘর যোগ করা হয়নি।


শেষ সপ্তাহের তারিখের বাস্তব সংশোধন (এই সংস্করণ):
- সক্রিয় renderCustomers override-এ তারিখ আগে গণনা হচ্ছিল কিন্তু HTML template-এ দেখানো হচ্ছিল না; এখন customer-paid লাইনের পরেই তারিখের লাইন যোগ করা হয়েছে।
- মূল renderCustomers fallback-এও lastWeekDate ভেরিয়েবল নির্ধারণ করা হয়েছে, যাতে undefined reference না থাকে।
- হিসাব: startDate + weeks × 7 দিন; ১২ সপ্তাহ হলে ৮৪ দিন।
