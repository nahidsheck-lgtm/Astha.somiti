আস্থা সমিতি — পূর্ণ অ্যাপ + Google/Gmail লগইন + Firebase Sync

এই ZIP-এ ডেমো নয়, সম্পূর্ণ অ্যাপের ফাইল রাখা হয়েছে। মূল গ্রাহক, কিস্তি, জমা, রিকভারি, ক্যাশ হিসাব, WhatsApp, রিপোর্ট, চুক্তিপত্র, ব্যাকআপ ও অন্যান্য পেজ/ফিচার রাখা হয়েছে।

আপনার বলা দৃশ্যগত পরিবর্তন:
- আপনার দেওয়া অরিজিনাল লোগো assets/logo.png হিসেবে রাখা হয়েছে।
- লোগো ও আস্থা সমিতির নাম উপরের সাদা অংশে মাঝখানে রাখা হয়েছে।
- লাল Google লগআউট বাটন Settings-এর একদম নিচে রাখা হয়েছে; হেডারে নয়।

লগইন ও Sync:
- অ্যাডমিন প্রবেশ Google/Gmail দিয়ে। আলাদা মোবাইল/PIN লগইন স্ক্রিন নেই।
- Firebase Authentication-এ Google চালু এবং GitHub Pages domain Authorized domains-এ থাকতে হবে।
- প্রতিটি Google UID-এর তথ্য Firestore-এর appSettings/{uid} ডকুমেন্টে আলাদা থাকে।
- একই Gmail দিয়ে অন্য ফোনে লগইন করলে ওই Gmail-এর Firestore ডেটা আসবে।

GitHub-এ দেওয়ার আগে:
1. বর্তমান GitHub repository-এর ফাইলগুলো আগে ডাউনলোড করে ব্যাকআপ রাখুন।
2. ZIP-টি ফোন/কম্পিউটারে Extract করুন। ZIP ফাইলটিকে সরাসরি GitHub-এ index হিসেবে আপলোড করবেন না।
3. Extract করা ফোল্ডারের index.html, firebase-app.js, firebase-config.js, sw.js, manifest.webmanifest এবং assets ফোল্ডার GitHub repository-এর root-এ দিন। index.html ও firebase-app.js প্রতিস্থাপন করতে হবে।
4. Firebase Console → Authentication → Sign-in method-এ Google Enabled আছে নিশ্চিত করুন।
5. Firebase Console → Authentication → Settings → Authorized domains-এ nahidsheck-lgtm.github.io আছে নিশ্চিত করুন।
6. Firestore Rules যাচাই ছাড়া বদলাবেন না। এই অ্যাপের নতুন Sync path হলো appSettings/{uid}; ওই path-এ request.auth.uid == uid শর্ত থাকা দরকার। অন্য collections-এর আপনার বিদ্যমান rules অকারণে মুছবেন না।
7. GitHub Pages আপডেট হওয়ার পর সাইটটি Chrome-এ খুলে Google দিয়ে লগইন পরীক্ষা করুন। পুরোনো PWA cache থাকলে Chrome-এ সাইট reload করুন।

ডেটা সতর্কতা:
- প্রথমবার Gmail লগইন করলে ফোনে থাকা লোকাল ডেটা ক্লাউডে পাঠানোর অনুমতি চাইতে পারে। সঠিক ডেটা আছে দেখে তবেই Yes দিন।
- অন্য Gmail দিয়ে লগইন করলে আলাদা UID-এর ডেটা খুলবে।
- Firestore-এ সম্পূর্ণ অ্যাপ ডেটা একটি document-এ রাখা হয়; Firestore document size limit 1 MiB। অনেক বড় ফাইল/ডেটা থাকলে আলাদা storage/document design লাগতে পারে।
- গুরুত্বপূর্ণ পরিবর্তনের আগে JSON backup ডাউনলোড করে রাখুন।

পরীক্ষার অবস্থা:
- ZIP archive পরীক্ষা করা হয়েছে এবং ফাইলগুলো ঠিকভাবে extract হয়।
- HTML-এ Google login entry point, Firebase module, config, UID-ভিত্তিক Firestore path এবং Settings-এর নিচে logout button যাচাই করা হয়েছে।
- আপনার Firebase Console-এর live settings, GitHub Pages deployment এবং ফোনে বাস্তব Google sign-in/Firestore sync এখানে থেকে পরীক্ষা করা সম্ভব হয়নি। তাই আপলোডের পর live login সফল হয়েছে বলে এখনই নিশ্চয়তা দেওয়া যাচ্ছে না।
